MCP da Base Nacional Comum Curricular

An MCP for Brazil's National Common Curricular Base

Um projeto piloto que disponibiliza, de forma aberta e gratuita, todas as habilidades da BNCC a assistentes de IA — para que ChatGPT, Claude e outros consultem uma fonte oficial em tempo real, em vez de depender da memória do treinamento.

A pilot project that openly and freely makes all of the BNCC skills available to AI assistants — so that ChatGPT, Claude and others can query an official source in real time, instead of relying on training memory.

O que é

What it is

O MCP da BNCC é um projeto piloto desenvolvido por mim com o Claude Code que disponibiliza de forma aberta e gratuita todas as habilidades da Base Nacional Comum Curricular, organizadas por etapa, série, unidade temática e o objeto de conhecimento. O projeto também inclui as habilidades prioritárias conforme o Mapa de Foco do Instituto Reúna, indispensáveis para iniciativas de recomposição de aprendizagens.

The BNCC MCP is a pilot project I developed with Claude Code that openly and freely makes available all of the skills (habilidades) of the National Common Curricular Base, organized by stage, grade, thematic unit and object of knowledge. The project also includes the priority skills defined by Instituto Reúna's Focus Map (Mapa de Foco), essential for learning-recovery initiatives.

O que é um MCP

What an MCP is

Pra quem não conhece, MCP (Model Context Protocol) é um padrão aberto que permite conectar assistentes de IA a fontes de dados e ferramentas externas. Com ele instalado, ao invés do ChatGPT ou Claude dependerem de informações absorvidas no seu treinamento ou de buscas na web para uma análise à luz da BNCC, eles passam a consultar uma fonte oficial em tempo real, garantindo maior confiabilidade, rastreabilidade e evitando alucinações.

For those unfamiliar, MCP (Model Context Protocol) is an open standard for connecting AI assistants to external data sources and tools. Once installed, instead of ChatGPT or Claude relying on information absorbed during training or on web searches to analyze something in light of the BNCC, they query an official source in real time — improving reliability and traceability while avoiding hallucinations.

Para quem é útil

Who it's for

Para professores desenvolvendo planos de aula, autores produzindo recursos didáticos, desenvolvedores produzindo apps educacionais ou pesquisadores analisando recursos textuais com ajuda de agentes de IA, é um recurso útil, simples e totalmente gratuito.

For teachers developing lesson plans, authors producing instructional materials, developers building educational apps, or researchers analyzing text with the help of AI agents, it is a useful, simple and entirely free resource.
